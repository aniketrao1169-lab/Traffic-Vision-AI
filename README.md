# Traffic Vision AI

Traffic Sign Recognition using Convolutional Neural Networks.

## Features
- Traffic sign image recognition
- CNN-based classification
- 43 traffic sign classes
- GTSRB dataset
- Streamlit web interface
- Confidence analysis
- Prediction history

## Technologies
Python
TensorFlow / Keras
Streamlit
NumPy
Pillow
OpenCV

## Model
Architecture: CNN
Dataset: GTSRB
Input Size: 32 × 32
Classes: 43
